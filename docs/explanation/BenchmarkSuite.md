# BenchmarkSuite

Benchmarking utility for MOC vs optimized geometries.

## Fields

- `mocGeometry`: MOC-based geometry.
- `optimizedGeometry`: Optimized candidate geometry.
- `evaluator`: CFDSimulation evaluator.

## Methods

### `runAll()`

Evaluates both geometries.

### `compare()`

Compares results and returns deltas.
